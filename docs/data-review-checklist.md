# Data review checklist

## Blueprint transcription

- [ ] Initiative identity matches the printed Blueprint table.
- [ ] Pillar and strategic action are correct.
- [ ] Objective, description, intended outcome, target, timeline, and lead agencies preserve the source meaning.
- [ ] Printed page is recorded and visually checked.
- [ ] Horizon classification matches Table 5.1 totals.
- [ ] No current implementation claim was inferred from the 2023 Blueprint.

## Current evidence pilot

- [ ] Every current claim is tied to a directly opened, dated source.
- [ ] The source names the exact initiative, programme, project, or KPI.
- [ ] Original and revised targets remain distinguishable.
- [ ] Status wording does not exceed the evidence.
- [ ] Missing evidence appears as `No current evidence`.
- [ ] A non-pilot initiative is described as unreviewed, not as having no evidence.
- [ ] Every update cites a source identifier present on the same initiative record.
- [ ] Every source records publisher, publication date, access date, type, supported fields, and confidence.
- [ ] Outcome values retain their measurement period and a comparability caveat where needed.
- [ ] No percentage complete is inferred from unlike indicators or elapsed time.
- [ ] Exactly two pilot initiatives are selected from each pillar.

## Release checks

- [ ] `npm run check:content`
- [ ] `npm run lint`
- [ ] `npm run build:local`
- [ ] canonical English routes and legacy BM entry points inspected
- [ ] light and dark themes inspected
- [ ] keyboard expansion and filters inspected
- [ ] 320px, 390px, tablet, and desktop widths inspected
- [ ] no PCDS-specific copy or old domain remains in user-facing output
